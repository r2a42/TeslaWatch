This is a watch-only app. It is made for an Apple Watch that is managed from a family member's iPhone and has no iPhone of its own. It is for retrieving items from a vehicle: lock, unlock, trunk and frunk only. It cannot start or drive the vehicle, and the code contains no command that could. The iOS target is only the required container for a watch-only app and has no functionality.

The app talks to the user's own vehicle over Bluetooth LE using the manufacturer's published vehicle command protocol. It cannot be exercised without that vehicle.

The app has no account system and no network calls, and it collects no data. Encryption is limited to standard algorithms from Apple's CryptoKit, so it declares ITSAppUsesNonExemptEncryption = NO.

No demo account is needed (there is no sign-in).
